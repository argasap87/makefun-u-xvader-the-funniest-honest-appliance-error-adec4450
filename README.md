An entry for [The Funniest Honest Appliance Error](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450) — one line, the funniest honest error message an appliance could show.

> "Unbalanced load. Your duvet has rolled into a ball and is throwing itself against my walls. I cannot help you."

The hook: a washing machine reports the true fault — an unbalanced load — in its own flat, put-upon voice. The duvet has rolled into a ball and is beating itself against the drum walls, and instead of politely asking for help, the machine simply refuses to do anything about it. The laugh comes from the machine's deadpan honesty: it names the fault plainly, then quits on the spot.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
